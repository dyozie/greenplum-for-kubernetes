# Prerequisites

The following topics describe how to install and configure the software necessary to run {{#include ./product_name_long.md}}:

* [Kubernetes Node Configuration](node-requirements.html) describes the Linux kernel configuration requirements for each Kubernetes node that is used in a {{#include ./product_name.md}} cluster. These requirements are common to all {{#include ./product_name.md}} deployments, regardless of which Kubernetes environment you use.

* [Minikube](prepare-minikube.html) describes software requirements for deploying to Minikube. A Minikube installation enables you to demonstrate {{#include ./product_name.md}} on a single-node system (your local machine), using minimal resources. It is not supported for production deployments.

* [VMware Tanzu Kubernetes Grid Integrated (TKGI) Edition running on Google Cloud Platform (GCP)](prepare-pks.html) describes software and configuration requirements for VMware Tanzu Kubernetes Grid Integrated (TKGI) Edition on Google Cloud Platform. This is a recommended environment for evaluating, testing, or running workloads on {{#include ./product_name.md}}.

* [Google Kubernetes Engine (GKE) running on Google Cloud Platform (GCP)](prepare-gke.html) describes software and configuration requirements for GKE on Google Cloud Platform. This is a recommended environment for evaluating, testing, and running workloads on {{#include ./product_name.md}}.
